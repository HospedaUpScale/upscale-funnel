Instruções de Apontamento DNS (IP da VPS: 179.198.96.35)
Para vincular seu domínio ou o de um cliente, acesse o painel onde registrou seu domínio (Hostinger, Registro.br, Cloudflare) e adicione as entradas:
  • Entrada Tipo A (Recomendado): Host @ (ou subdomínio) apontando para o IP: 179.198.96.35
  • Entrada www: Tipo CNAME, Host www apontando para o domínio principal.
  • Easypanel: Adicione o domínio na aba Domínios do Easypanel para gerar o certificado SSL (HTTPS) com cadeado verde.
Instruções para Cloudflare (SSL & Proxy)
Se utiliza Cloudflare, configure o modo SSL para Full (Completo) ou Strict e certifique-se de que a nuvem de proxy esteja ativada (Laranja).

Token de API do workspace

Este token autentica os webhooks das plataformas. Por segurança ele não fica salvo em texto: gere um novo e cole nos webhooks abaixo. Gerar um novo invalida o anterior.

Webhooks do workspace

Cadastre cada URL na plataforma indicada. Envie o token em Authorization: Bearer SEU_TOKEN ou, se a plataforma não permitir cabeçalhos, use a URL com ?token= (gere o token acima e o botão já copia a URL com ele). Na venda, mande também o ID da rifa (rifa_id ou campaign_id) para o card abrir a oferta da campanha certa.
