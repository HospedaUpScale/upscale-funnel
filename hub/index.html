Como Plugar Qualquer Plataforma de Rifas à Rede upScale Media

A upScale Media Network é a nova rede de monetização e upsell. Para conectar plataformas como Sorteamos, Play55 ou qualquer checkout externo, basta copiar as credenciais abaixo:

Snippet de Incorporação (Iframe Embed & Bridge PostMessage)

Para embutir diretamente na página de obrigado da rifa com auto-ajuste de altura: 

<iframe id="upscale-frame" src="https://oferta.vendedorsincero.pro/index.html?nome={{nome}}" style="width:100%;border:0;height:820px;"></iframe>
<script>
window.addEventListener('message', function(e) {
  if (e.data && e.data.tipo === 'dx:altura') {
    document.getElementById('upscale-frame').style.height = e.data.altura + 'px';
  }
});
</script>
