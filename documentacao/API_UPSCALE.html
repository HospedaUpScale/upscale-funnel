API & Webhook Oficial da Rede upScale

Documentação para plataformas de rifas (Sorteamos, Play55, SorteiMe ou checkout próprio) receberem eventos de compras de cotas e renderizarem o Booster / Raspadinha de Alta Conversão em tempo real.

1
Venda de Bilhetes na Rifa

O comprador paga o Pix na plataforma de rifa.

2
Disparo do Webhook

A rifa chama o webhook oficial da upScale com os dados da venda.

3
Card Personalizado

A upScale valida a compra mínima, ativa o bônus e devolve o Iframe pronto.

4
Pix de Upsell 1-Clique

O comprador raspa na tela e converte cotas extras com split liquidado.

POST

/api/v1/webhook

A plataforma de rifas dispara este webhook assim que a compra de cotas for aprovada. A upScale registra o comprador, avalia o bônus de R$ 50.000 e gera o token de acesso exclusivo para a tela de obrigado.

Exemplo de Chamada (cURL / HTTP POST)
curl -X POST https://seudominio.com/api/v1/webhook \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SEU_TOKEN_DO_WORKSPACE" \
  -d '{
    "order_id": "PED-98432",
    "customer": {
      "name": "Carlos Alberto Silva",
      "phone": "11987654321",
      "cpf": "12345678900"
    },
    "amount": 60.00,
    "quotas": 100,
    "status": "paid"
  }'

Parâmetros aceitos no JSON:

Campo Tipo Obrigatório Descrição
order_id String Sim Identificador único do pedido na plataforma de rifa (ex: PED-98432).
customer.name String Sim Nome completo do comprador. A API extrai o primeiro nome para a raspadinha.
customer.phone String Opcional Telefone/WhatsApp com DDD (ex: 11999999999) para recuperação e Pix.
amount Number Sim Valor total pago na rifa (ex: 60.00). Usado para validar a compra mínima do bônus.
status String Sim Status do pagamento: paid, pago ou confirmed.

GET

/api/v1/offer

Consulta pública dos dados da campanha e oferta ativa (título, preço, cotas do booster, timer de urgência e valores de bônus).

Exemplo de Requisição
curl -X GET https://seudominio.com/api/v1/offer?workspace_id=2
GET

/api/v1/winner

Permite ao organizador da rifa auditar e validar se o ganhador de uma cota premiada comprou pelo card da raspadinha e tem direito aos R$ 50.000 extras.

Exemplo de Consulta de Ganhador
curl -X GET "https://seudominio.com/api/v1/winner?order_id=PED-98432" \
  -H "Authorization: Bearer SEU_TOKEN_DO_WORKSPACE"

Como incorporar o Iframe na Página de Obrigado da Rifa

A plataforma de rifa pode simplesmente embutir este Iframe na tela de conclusão de pagamento. O script ajusta a altura automaticamente eliminando qualquer barra de rolagem.

HTML para a tela pós-compra da rifa
<div style="width:100%;max-width:680px;margin:0 auto;">
  <iframe 
    id="upscale-frame" 
    src="https://seudominio.com/?workspace_id=2&nome={{nome}}&valor={{valor}}" 
    style="width:100%;border:0;min-height:520px;" 
    scrolling="no">
  </iframe>
</div>

<script>
window.addEventListener('message', function(e) {
  if (e.data && e.data.tipo === 'dx:altura') {
    document.getElementById('upscale-frame').style.height = e.data.altura + 'px';
  }
});
</script>
