Integração da Raspadinha Booster 110X

Manual com os snippets, cabeçalhos Apache e instruções para publicar na Hostinger e embutir na rifa.

Escolha o Cenário de Hospedagem:

1. Estrutura de Arquivos na Hostinger

No painel da Hostinger (hPanel → Gerenciador de Arquivos), crie a pasta /public_html/rasp2/ e envie os arquivos:

Estrutura no Servidor
public_html/
└── rasp2/
    ├── index.html       (O card consolidado da raspadinha)
    ├── .htaccess        (Configuração de cabeçalhos sem restrição)
    ├── teste/
    │   └── index.html   (Ferramenta de diagnóstico)
    └── integracao/
        └── index.html   (Esta documentação)

2. Arquivo .htaccess

Garante que a Hostinger não bloqueie a raspadinha dentro do iframe com o header SAMEORIGIN.

/public_html/rasp2/.htaccess 
Header always unset X-Frame-Options
Header unset X-Frame-Options
Header always set Content-Security-Policy "frame-ancestors *;"
Header always set Access-Control-Allow-Origin "*"

3. Bloco para Colar na Rifa (Página de Sucesso / Obrigado)

Cole este bloco HTML + JavaScript no painel da rifa onde o comprador finaliza a compra:

embed-rifa.html 
<div style="width:100%;max-width:680px;margin:0 auto;">
  <iframe
    id="iframe-booster"
    src="https://oferta.vendedorsincero.pro/rasp2/"
    style="width:100%;min-height:420px;border:none;overflow:hidden;display:block;"
    scrolling="no">
  </iframe>
</div>

<script>
window.addEventListener('message', function(e) {
  if (e.data && e.data.tipo === 'dx:altura' && e.data.altura) {
    var f = document.getElementById('iframe-booster');
    if (f) f.style.height = e.data.altura + 'px';
  }
});
</script>
