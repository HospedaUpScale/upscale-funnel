Integração da Raspadinha Booster 110X

Plataforma: Sorteamos.com.br • Campanha: Vendedor Sincero • Destino: Tela de Pagamento Aprovado

1. Como Funciona

O widget é incorporado via <iframe> na página de confirmação de pedido da Sorteamos. Os dados do comprador são passados diretamente na URL através de parâmetros simples (ex: ?nome={{customer.name}}).

O card ajusta sua própria altura automaticamente sem gerar barras de rolagem duplas no celular, e o botão de compra redireciona a tela inteira para o checkout do Booster.

2. Código de Incorporação (Embed Pronto)

Cole o bloco abaixo na página de pedido concluído / pagamento aprovado:

Snippet HTML + JavaScript 
<!-- WIDGET BOOSTER 110X - VENDEDOR SINCERO -->
<div id="wrapper-booster-110x" style="width:100%; max-width:680px; margin:20px auto; padding:0 10px;">
  <iframe 
    id="iframe-booster-110x"
    src="https://oferta.vagnerpecuaria.site/?nome={{customer.name}}"
    style="width:100%; min-height:420px; border:none; overflow:hidden; display:block; background:transparent; transition:height 0.25s ease;"
    scrolling="no"
    loading="eager"
    allow="clipboard-write">
  </iframe>
</div>

<script>
  // Redimensionamento automático de altura (dx:altura)
  window.addEventListener('message', function(event) {
    if (event.data && (event.data.tipo === 'dx:altura' || event.data.altura)) {
      var frame = document.getElementById('iframe-booster-110x');
      var h = event.data.altura;
      if (frame && typeof h === 'number' && h > 50) {
        frame.style.height = h + 'px';
      }
    }
  });
</script>
Nome do Comprador: Substitua {{customer.name}} pela variável ou tag de template utilizada pelo sistema da Sorteamos. Caso o cliente não tenha nome informado, o card se adapta automaticamente para um texto seguro.

3. Parâmetros Aceitos na URL

Parâmetro Tipo Descrição Exemplo
nome Opcional Nome do comprador para personalizar o topo e a raspadinha. ?nome=Isaias
checkout Opcional Link de checkout customizado (caso deseje passar parâmetros de pedido). ?checkout=https://sinceropremios.com/pay/...
utm_* Opcional Tags UTM de rastreamento mantidas no funil de conversão. ?utm_source=pos-compra

4. Segurança e Permissões de Iframe

O servidor oferta.vagnerpecuaria.site já possui cabeçalhos liberados no .htaccess autorizando a incorporação dentro de https://sinceropremios.com e https://sorteamos.com.br com CORS liberado.
